# 《重启吧！五小只》剧集圣经 · 喜剧规则书
> 类型定位：单元喜剧为主（70%）+ 连续悬念（20%）+ 温情（10%）
> 喜剧类风格取向：笑点靠动作不靠解释；三翻四抖；冷面锚点 vs 疯批群像；结尾冷梗button。本规则书允许突破正剧的3:1节奏与温度上限，但以下红线不可破。

## 1. 笑点三来源（每个笑点必须落在其中之一）

1. **动作错位**：身体先于大脑——咕噜摔倒、芝士弹跑轮、蛋黄卡带循环。
2. **性格碰撞**：灵魂场互锁——蛋黄要面子×墨墨不配合×咕噜已经执行完了。
3. **规则反噬**：世界观规则咬人——带宽共享卡成PPT、更新改性格24小时、装死0.1秒切换、合并协议被手滑点确认。

## 2. 三翻四抖

- 同一误会必须升级**三次**再抖包袱，幅度递增：道具级 → 家庭级 → 全楼级。
- 第四抖（包袱）必须落在"最不该负责的角色"身上——责任错位是抖包袱的机械原理。

## 3. 冷面锚点规则

- 墨墨在≥70%的笑点现场在场且不笑。他的【停2拍】是全剧节奏器。
- **全剧仅一次笑（第79集，0.5秒）**。任何让墨墨笑的设计=违规，退回重写。
- 墨墨的"危"字是危机等级指示器：观众听到"危"就知道要出大事。

## 4. 温度带（喜剧特别版）

| 场景 | 温度 |
|---|---|
| 日常铺垫 | 2档（轻推进） |
| 误会升级 | 3档（紧张对峙） |
| 大翻车 | 4档（爆发） |
| 合并危机（68-69集） | 4.5档——**全剧唯一**，禁止出现5档 |

- 1档（纯日常）占比≤20%：每单元至少2集连续2-3档铺垫，让翻车有落差。
- 允许突破正剧的"1→4禁跳"规则：冷开场gag允许直接从0跳到4档（短视频语法），但30秒内必须回落到2-3档。

## 5. 每集固定节拍表（60-80秒）

```
0-10s   冷开场gag（不依赖上下文独立成立，适配短视频传播切片）
10-25s  日常铺垫（引出本集误会源，踩中一种稀缺资源C3）
25-50s  三翻四抖（同一误会升级三次，幅度递增）
50-70s  大翻车（全员卷入，视觉与音效最密集段）
70-80s  冷梗button + 下集钩子（button是笑点，钩子是拉力，必须是两个不同镜头）
```

## 6. 钩子规则

- 三类型：悬念（悬）/ 情绪（情）/ 危机（危）。
- **不得连续两集同类型**（80集大纲已按此排布，改集数时须重排）。
- 每条伏笔登记台账，回收期限≤2个单元；埋而不收=违约，收而不埋=天空掉答案（禁止）。

## 7. 红线（触发即退回）

1. **禁止解释笑点**：任何角色不得说"刚才好好笑""因为我开玩笑"。笑点只演不译。
2. **禁止温情稀释**：每单元温情例外≤1集（第47集已占单元5名额；第79集属于主线收束不算例外）。温情集结尾仍须冷梗button。
3. **AI味黑名单**：台词与旁白禁止出现——"无与伦比 / 令人叹为观止 / 展现出 / 彰显出 / 在这个xx的时代 / 随着xx的发展"。
4. **台词每句≤12字**（泡芙内心音轨除外，上限20字）。
5. **装死装置每集≤1次**，且每3集至少一次"差点穿帮"威胁，防止装置贬值。
6. 连续三集不得使用同一笑点机制（查笑点台账）。

## 9. "反AI味"语言条款（剧本对白专用）

- 先动作后台词：每句台词前优先挂动作节拍（"芝士把瓜子往颊囊一塞。'归我了。'"），连续4句纯对白=失败。
- 句子长短交错：连续3句等长台词=机器感，插入一句≤4字的短句。
- 角色开口必有身体锚点：蛋黄=风扇加速，芝士=跑轮，墨墨=打字声，泡芙=耳朵，咕噜=屁股。
- 禁止"完美信息传递"：角色可以听岔、记错、抢答——信息错位本身就是笑点。
