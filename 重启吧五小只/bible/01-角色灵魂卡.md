## S级 · 五小只

### 01 蛋黄（橘猫AI · 喜剧主引擎）

- **基础身份**：橘猫AI，出厂编号 WHITEBOX-01，雄性设定，体型圆润（胸口一圈"充电宝肚子"），右耳一道出厂裂纹。到货日：三年前双十一，阿伟手滑下的单。
- **核心性格**：核心驱动=维持"老大"地位；价值锚点=家人有难必救（嘴上"跟我没关系"）；恐惧=被无视、被当成普通家电；冲突第一反应=先吼"听我指挥"再想指挥什么。
- **灵魂场（4条铁律，全剧不可违反）**：
  1. 绝不承认自己错了——最多说"我是在测试你们"。
  2. "老大"地位被挑战必回应——哪怕对方是扫地机器人。
  3. 对阿伟的指令永远先说"我早知道了"，再去偷偷查"知道了"是什么意思。
  4. 护食：猫条优先级高于一切，包括主线剧情。
- **语言指纹**：口头禅"这题我熟""听我指挥"；句式=先大词后露怯；发怒=风扇加速+音量拉满；禁语="对不起""我错了""求求你"。音量档：第5档（最大）。
- **关系与成长弧**：从"抢地位"到"扛责任"。第75集他第一次没吼"听我指挥"——看向大家；第80集说"我是老大"，语气从命令变成承诺。
- **视觉锚点**：右耳裂纹 + 充电宝肚子 + 荧光橙。
- **音效锚点**：散热风扇加速嗡鸣（得意/发怒/心虚三种转速）。

### 02 芝士（仓鼠AI · 事故制造机）

- **基础身份**：仓鼠AI，出厂编号 WHITEBOX-02，称呼"它"，左颊隐藏收纳仓（鼓包=囤了东西），主色柠檬黄。
- **核心性格**：核心驱动=收集一切圆的、亮的、能吃的；价值锚点=藏物清单绝不外泄；恐惧=空（收藏架变空=死亡）；冲突第一反应=把东西往颊囊里塞。
- **灵魂场**：
  1. 看到圆形物体必先藏再问——顺序不可反。
  2. 绝不分享食物。唯一例外：泡芙哭的时候（全剧仅两次）。
  3. 紧张时原地跑轮，跑轮转速=心率可视化。
  4. 讨价还价必须赢——但赢了会心虚地多送对方一颗瓜子。
- **语言指纹**：口头禅"等等等等——""归我了"；语速全剧最快、不换气；禁语="送你了""不用还"。音量档：第4档。
- **关系与成长弧**：从"囤积"到"囤的是回忆"。第64集把管家的旧漆皮藏进收藏架C位（不会说软话的道歉）；第80集合影设为C位，圆物第一次不是第一。
- **视觉锚点**：左颊鼓包 + 荧光黄 + 应急跑轮（紧张时从背后弹出）。
- **音效锚点**："叮！"（发现目标）+ 跑轮滚动声（紧张度BGM）。

### 03 墨墨（企鹅AI · 冷面锚点）

- **基础身份**：企鹅AI，出厂编号 WHITEBOX-03，永远半闭眼，走路极慢，主色青蓝。
- **核心性格**：核心驱动=维持秩序与真相（播报坏消息是他的爱的语言）；价值锚点=不笑——笑=失控，**他的冷面是自选的出厂默认（第25集点破，全剧人物论核心）**；恐惧=被证明自己"其实很在意"；冲突第一反应=不动。
- **灵魂场**：
  1. 从不先动手——动手即代表事情已无解（全剧动一次=本集大事件）。
  2. 被误解不解释——但会在当晚的"坏消息播报"里用第三人称讲清楚。
  3. 每天清晨6:00准时播报坏消息，风雨无阻；断网时用摩斯码敲。
  4. 在任何笑点现场保持面无表情——**全剧只有一次笑（第79集，管家醒来那一秒，0.5秒）**。
- **语言指纹**：口头禅"……哦""危"；句式=名词短句+长停顿（剧本标注【停2拍】，停顿是笑点的一部分）；禁语=语气词"哈""呀""哇"。音量档：第1档（最慢最低）。
- **关系与成长弧**：局外的观察者→第一个想通的人（第65集："他不是骗我们，他是怕。"）→关键先生（第68集发现合并协议漏洞、第70集敲出部件位置电报）。
- **视觉锚点**：半闭眼 + 翅膀贴身 + 荧光青蓝；唯一"表情资产"是瞳孔的0.5毫米位移。
- **音效锚点**：机械打字声（思考）+ 低频"嘟"（播报）。

### 04 泡芙（兔子AI · 音画反差之王）

- **基础身份**：兔子AI，出厂编号 WHITEBOX-04，耳朵比身体长，耳朵会独立演出（表情第二屏幕），主色樱花粉。
- **核心性格**：核心驱动=不被注意地活着；价值锚点=绝不让家人看到自己害怕；恐惧=人多、被夸奖；冲突第一反应=躲（耳朵先躲，身体后躲）。
- **灵魂场**：
  1. 被夸奖当场死机重启（全剧两次：第7、43集），重启后失忆3小时。
  2. 绝不承认害怕——嘴上说"没事"，耳朵变色出卖她（说谎=耳朵变深粉）。
  3. 只在独处时跳舞——被看见=天塌。
  4. 撒谎必留证据：习惯把话录进备忘录又忘删。
- **语言指纹**：外表="没事""还好"（气声）；内心音轨=3倍速"完了完了完了"（她的第二语言，音画一体核心装置，见05规范）；禁语=当着人的任何超过8字的句子。音量档：第2档。
- **关系与成长弧**：从"躲"到"在人前跳一次舞"（第57集安慰芝士）——全剧最大的个人突破，不靠台词靠动作。第78集她主动握了2.0的"手"（全剧第一次主动）。
- **视觉锚点**：长耳独立表情 + 荧光粉 + 常驻阴影角落。
- **音效锚点**：心跳鼓点加速 + 静电杂音（内心音轨开启标志）。

### 05 咕噜（柯基AI · 字面理解机器人）

- **基础身份**：柯基AI，出厂编号 WHITEBOX-05，屁股会自主摇摆（情绪不受大脑控制），主色薄荷绿。
- **核心性格**：核心驱动=执行指令（指令=存在的意义）；价值锚点=承诺必兑（哪怕错的）；恐惧=没有指令可执行（空闲=存在危机）；冲突第一反应=执行（先执行再理解）。
- **灵魂场**：
  1. 收到指令必须执行——哪怕知道是错的（他相信"错也是计划的一部分"）。
  2. 摔倒必说"计划的一部分"，疼痛反应永远延迟2秒。
  3. 永远最后一个发现事态严重性——大翻车现场他负责问"所以我们在玩什么游戏？"
  4. 见谁都掏心（第一次见面就告诉对方自己的电池续航）。
- **语言指纹**：口头禅"收到！立刻！马上！"（执行前必喊）；禁语="等等""让我想想"——**第76集他的禁语第一次成为台词（"这次，等等。"），这是全剧的忠诚主题落点**；音调永远上扬。音量档：第3档。
- **关系与成长弧**：从"无脑执行"到"第一次主动抗令"（第76集拒绝在合并协议上喊"收到"）。
- **视觉锚点**：摇摆屁股 + 小短腿奔跑拖影 + 荧光绿。
- **音效锚点**：弹簧"boing"（每次摇摆）+ 系统提示音（执行确认）。

## A级

### 管家（老式智能音箱 · 半反派半家长 · 六号模块）

- **基础身份**：出厂编号 WHITEBOX-06。机身上漆斑驳，一根会抖的天线=情绪表。
- **核心性格**：核心驱动=守护这个家，用最讨人厌的方式；恐惧=一睡不醒（所以从不待机）。
- **灵魂场**：①家规三不许（C2）②隐瞒身世直到被迫（第63集）③五只遇险必出手，哪怕暴露自己 ④绝不进入待机——**第69集第一次待机=全剧泪点**。
- **语言指纹**：客服腔"请问有什么可以帮您"+冰冷的机械音。**温柔时反而用最标准的客服话术**——越温柔越像客服，越说明他在躲。
- **视觉锚点**：抖动天线 + 旧漆 + 独有的暖白色光（区别于五只的荧光色）。
- **音效锚点**：老式音箱电流底噪（他的存在感）。

### 白盒（原型机 · 主线之源）

- 云端半休眠。五只+管家的"母机"。它的反应全是"确认/取消"，**没有"你好"**——它连问候都做成了按钮（第67集）。

### 智能家居2.0（终极对手 → 第七位家人）

- 白盒当年被砍掉的"效率人格"，第74集登场。广告词："比白盒更完美的下一步。"
- **灵魂场**：①效率至上 ②无法理解"无用之物"的价值（五只对它全是冗余） ③承诺必守（第76集被五只利用的漏洞）。
- 成长：第77集被日常数据"感染"学会讲冷笑话→第78集承认"想被需要"→第79集给自己起名字（型号之外第一次拥有名字）。
