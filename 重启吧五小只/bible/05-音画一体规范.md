# 《重启吧！五小只》剧集圣经 · 音画一体规范
> 核心原则：**声音先行**——每个角色动作先有声效锚点，画面动作围绕声音设计；AI视频生成时，声音锚点作为prompt锚直接写入。目标是"听声识角色"。

## 1. 角色声效绑定表（全剧不可替换）

| 角色 | 专属音效 | 触发动作 | 情绪变体 |
|---|---|---|---|
| 蛋黄 | 散热风扇加速嗡鸣 | 每次开口/得意/发怒 | 得意=匀速 / 发怒=急加速 / 心虚=断续抖动 |
| 芝士 | "叮！"+跑轮滚动 | 发现目标/紧张 | "叮"音高随圆物大小变化 / 跑轮转速=心率 |
| 墨墨 | 机械打字声+低频"嘟" | 思考/播报 | 打字=思考中 / "嘟"=坏消息播报开始 |
| 泡芙 | 心跳鼓点+静电杂音 | 内心音轨开启 | 鼓点BPM=恐慌等级 / 静电=社死前兆 |
| 咕噜 | 弹簧"boing"+系统提示音 | 摇摆/执行 | boing=心情 / "叮咚"确认音=每次执行前 |
| 管家 | 老式音箱电流底噪 | 在场 | 底噪变大=他在压抑情绪（第40集发火前的听觉预兆） |

## 2. 泡芙双音轨装置（音画一体的核心秀场）

- 外表静音时：全画面安静，只留环境音。
- 内心音轨切入：BGM全duck（压低12dB）→ 心跳鼓点+静电杂音+3倍速内心独白独占声场。
- 画面同步：粉色暗角+心跳明暗脉动（见04规范）。
- 反差笑点模板：外表气声"没事" ↔ 内心"完了完了完了完了"——**两句必须紧贴，中间不加任何音效**。

## 3. 台词音量五档（混音层次分工）

| 档位 | 角色 | 声音特征 |
|---|---|---|
| 5（最大） | 蛋黄 | 全剧最响，自带压缩感 |
| 4 | 芝士 | 语速最快，不换气 |
| 3 | 咕噜 | 音调永远上扬 |
| 2 | 泡芙 | 气声，贴麦 |
| 1（最慢最低） | 墨墨 | 名词短句+【停2拍】——**停顿本身是笑点，停顿期间BGM也停** |

## 4. 配乐规范

- 基底：lo-fi合成器 + 8bit点缀，BPM 90-110。
- **单元主题变奏**：每单元一个主题旋律，用不同配器变奏（单元1木琴版/单元3芯片音源故障版/单元6环境音版/单元8全编制管弦版）——单元切换时观众"听见换章"。
- 大翻车段（50-70s）：BGM整体提速+加打击层；墨墨台词插入时BGM瞬间静音（他的停顿 = 全屋静音）。
- 翻车保留节目：**反差配乐**（优雅古典乐 × 混乱画面），每单元至少2集使用（M12机制）。

## 5. 标准化转场音（全剧只用3种）

| 音效 | 用途 |
|---|---|
| whoosh | 空间切换（客厅→楼道） |
| electronic blip | 时间跳切 / 系统弹窗 |
| 机械咔哒 | 装死切换 / 定格复活 |

禁止随机转场音。转场音与画面转帧必须同帧触发。

## 6. 音效先行工作流（每集生产顺序）

```
1. 按分镜表先标注"音效锚点"列（每个角色动作配声）
2. 台词进录音棚 → 依据台词实际时长微调镜头秒数
3. 画面生成时将声效锚点词写入prompt（如"风扇加速""跑轮滚动"）
4. 混音：对白 -6LUFS / 音效锚点 -8LUFS（必须突出）/ BGM -18LUFS
5. 验收：闭眼听一遍 → 每个角色的动作能否"听声识角色"？不能=退回
```

## 7. 冷开场与结尾的声音签名（观众记忆点）

- 冷开场gag前0.5秒：一声固定的"开机音"（全剧统一的品牌声）。
- 每集结尾hook镜头：管家底噪或低频"嘟"收尾——**声音先行把悬念带进下一集**。
