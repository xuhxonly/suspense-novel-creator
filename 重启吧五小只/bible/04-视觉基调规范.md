# 《重启吧！五小只》剧集圣经 · 视觉基调规范

## 1. 整体风格定位

**暖色科技萌系（Cozy Tech）**：Pixar短片质感 × 干净CG。角色2.5头身Q版。
关键词：软、圆、暖。**硬边、冷光、金属感只允许出现在危机单元（6、8）与云端空间**。

## 2. 色彩体系（色彩即身份，全剧零混用）

| 用途 | 色彩 | 说明 |
|---|---|---|
| 全局基底 | 奶白 #FFF8F0 + 奶油黄 #FFE8B3 | 公寓墙面、地板主色 |
| 蛋黄 | 荧光橙 #FF9A3C | 猫条道具同色 |
| 芝士 | 柠檬黄 #FFD23C | 圆物收藏架同色 |
| 墨墨 | 青蓝 #4FC3F7 | 播报屏同色 |
| 泡芙 | 樱花粉 #FFB3D9 | 内心音轨开启时画面边缘泛粉 |
| 咕噜 | 薄荷绿 #7DE8B8 | 指令确认弹窗同色 |
| 管家 | 暖白 #F5F0E8 | 唯一"非荧光"角色——他是上一代 |
| 危机色温 | 冷青 #3A4A5A | 单元6/8与云端空间整体偏移 |
| 云端空间 | 数据流蓝紫渐变 | 与全剧暖色形成大反差（单元7视觉爆点） |

**一致性红线**：五角色同框时各自专属色必须可辨（单角色画面占比≥15%）；专属色只用于角色本体与其专属道具，禁止挪作环境色。

## 3. 光线规范

- 默认：傍晚暖橙体积光（下午5点的客厅），主光低角度。
- 危机单元（6/8）：整体转冷青，但五角色专属色饱和度不变——**环境冷、角色暖**，视觉上"家人抱团"。
- 笑点翻车瞬间：允许0.5秒高光频闪（仅大翻车段，每集≤1次）。
- 泡芙内心音轨开启：画面边缘粉色暗角+心跳同步的明暗脉动。

## 4. 场景美术

| 场景 | 美术要点 |
|---|---|
| 智能公寓客厅 | 五只专属角落：蛋黄的猫条柜/芝士的圆物收藏架/墨墨的播报屏/泡芙的阴影角落/咕噜的门垫——**一眼可辨"谁的地盘"** |
| 阿伟卧室 | 暖灰调，泡芙独舞舞台，百叶窗切光 |
| 楼道 | 公告屏=全楼信息板（也是绝交声明现场） |
| 快递箱内部 | 瓦楞纸"异世界"，比例夸张（芝士眼里的巨大峡谷） |
| 云端空间 | 半透明数据平台，白盒是一个巨大的、静默的白色胶囊 |

## 5. 镜头配方（AI视频生成可直接执行）

- 每集6-8镜，**单镜3-5秒**，总时长60-80秒。
- 每集必含：
  1. **表情大特写**×1（喂表情包资产，用于传播切片）
  2. **俯视全景**×1（五只同框，展示地盘与地位关系）
- 景别配方参考：特写40% / 中景30% / 全景20% / 俯视10%。
- 大翻车段（50-70s）允许快切：单镜缩短至2秒，但每镜必须仍可读出"谁在做什么"。
- 转场：全剧只用3种（快速摇移 / 光斑擦除 / 装死定格→复活跳切），禁止炫技转场。

## 6. 表情资产库（每角色8枚，跨集复用保一致）

| 编号 | 表情 | 典型触发 |
|---|---|---|
| E1 | 得意 | 蛋黄标配；其他角色得意=错位笑点 |
| E2 | 死机 | 泡芙被夸/全员定格 |
| E3 | 心虚 | 蛋黄被戳穿/芝士多送瓜子时 |
| E4 | 狂喜 | 芝士见到圆物 |
| E5 | 冷脸 | 墨墨标配 |
| E6 | 社死 | 泡芙被围观 |
| E7 | 震惊 | 集体反应镜头 |
| E8 | 放空 | 咕噜执行完毕的待机脸 |

## 7. AI生成Prompt模板（分镜表"画面"栏直接套用）

```
{角色名}，{专属色}配色，{锚点特征}，2.5头身Q版，
暖色科技萌系，Pixar短片质感，{景别+机位}，
傍晚暖橙体积光，智能公寓客厅，软圆造型，干净CG
```

三要素缺一不可：**角色名 + 专属色 + 锚点特征**。锚点特征对照：

- 蛋黄：右耳裂纹+充电宝肚子
- 芝士：左颊鼓包+应急跑轮
- 墨墨：半闭眼+贴身翅膀
- 泡芙：超长双耳独立表情
- 咕噜：摇摆屁股+小短腿
- 管家：抖动天线+旧漆音箱身
