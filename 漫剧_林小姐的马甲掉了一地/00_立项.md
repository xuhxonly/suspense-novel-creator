# 阶段一｜立项书
## 《林小姐的马甲掉了一地》

### 一、赛道判断
- **主赛道（70%）**：归来复仇。三年沉冤+强势归来+信息差碾压。
- **副赛道（30%）**：马甲大佬。三层马甲逐层揭面（医学天才NIGHT→清池继承人→黑客"鸦"）。
- **赛道微调声明**：原默认"重生复仇"调整为"归来复仇"。理由：①规避重生题材审核雷区；②"三年消失归来"与"马甲"天然咬合——复仇的每一步都是揭一层马甲；③信息差碾压内核完整保留。
- **受众画像**：女性向为主（18–40），打脸+命案悬疑结构男女通吃。

### 二、一句话故事（26字）
被逐三年的养女归来，层层掉马甲，把两代人的血债连本带利收回来。

### 三、三集留存钩子设计
- **第1集**：回归夜受辱，住进柴房；爷爷病危，营养液标签被撕——观众知"局"存在。
- **第2集**：她急救压场露医术；药渣里验出三年慢毒"青蔓碱"——观众知"她在查"。
- **第3集**：汤局打脸表姐；金手指反噬首次失明——观众知"爽有代价"。三集完成：人设+能力+代价+悬念四件套。

### 四、对标与差异化
- 对标：《夫人的马甲又掉了》《大小姐她又美又飒》类爆款结构。
- 差异化（人无我有）：
  1. **复仇硬度**：不止情场打脸，是两代人命案（12年前车祸案+3年前毒案双线）；
  2. **金手指有价**：读心反噬→失明，时长递增——每次爽都有痛感，全市场稀缺；
  3. **吊命悬念引擎**：爷爷被"吊命"三年——不是谋杀是僵局，"为什么吊着"本身就是贯穿全剧的倒计时；
  4. **反派不降智**：四级反派阶梯，人人有铁律，AI味反派的通病被制度性锁死。

### 五、全剧基调
热血爽感。爽点密度每集1–2个峰值；情感线浓度≤20%（男主陆时砚）。

- [x] 倒计时装置：爷爷吊命 → 越拖越危险，天然催节奏
