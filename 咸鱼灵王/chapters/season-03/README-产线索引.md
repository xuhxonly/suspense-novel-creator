**季终状态快照**（接第四季《大话灵缘》）：
- 咸鱼：翻案夜挡击吐血（裂一鳞）后再度沉眠；睡前留下"北境"二字——S4 行程的罗盘
- 小才：官凭+创例簿在身（革职令随法旨被收走）；背篓里有火种、蛋挞、堂规抄本
- 阿糖：无罪开释，留守城寨（赎魂罐"赎羽"计划启动）；双符之一在她袖中——73集偷跑的引信
- 灵婆：狮吼后重伤卧床，阁老印已移交小才（"印在，规矩在"）
- 邪叟：一秒制服鹰派后回归看戏位；蛋挞之约＝S4回程钩
- 厉崇梧（鹰派）：被无相阁法旨带走灭口；"崇"字半谜已拼全
- 白算天：主考官身份公开→名册"相"字微失态→送行未现身；拂尘握白收束（S4立场待爆）
- 对穿肠：58集呕血、68集闭嘴倒戈（不洗白）；折扇与脸面并存
- 无相阁：玄鸦收回雏印、法旨、鹰派；"相"字名册抄本三份留在人间（铁嘴宋规矩）
- 老云头：已殉案；砖洞呈文+掌心骨形=灵矿线的官面证据（其子云捕头S5登场）
- 全城：十万盏灯未摘；堂官创例簿随行；公堂青石裂缝未修（S4的街景遗产）
