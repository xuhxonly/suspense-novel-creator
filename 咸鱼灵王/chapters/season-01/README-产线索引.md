**季终人物状态快照**（接第二季）：
- 咸鱼：王源损耗中，左眼金纹半成；正主已"找到它"
- 小才：守梦/护鱼立场公开化，与厉右使（鹰派）正面结仇
- 灵婆：重伤，怀疑升级到"王爷"二字
- 阿糖：羽针托付在身，针雨雀空壳待救（25集泪点引线）
- 白算天：暗护实锤，七日之拖开始
- 雷虎：败退消失（二季不再出现）
- 无相阁：黑旗军暂退，玄鸦复命，"伪王印"计划立项

**第二季开集（ep25）承接钩**：咸鱼觉醒后饭量×100——爽点反差开场；针雨雀之魂能否赎回=夺灵黑市线（56集）引线。
