**季终状态快照**（接第三季《九品兽官》）：
- 咸鱼：长眠（睡梦罗汉诀前夜——它在给自己造梦）；王源见底；玄鸦带走裂而未碎的骨片
- 小才：被官方定为"祸源兽主"嫌疑；救鱼之法成谜
- 灵婆：重伤未愈，"王爷"二字已经说出口；名单最后一行仍空
- 阿糖：接掌针雨雀+针谱（47集大托付兑现）
- 白算天：被迫与厉右使同袍——他站在了执法队里（S3立场撕裂的火药）
- 庖离：回宗查膳录失踪案（S3暗线友军）
- 无相阁：玄鸦复命，碎片裂而未碎；"相"印首次亮相
- 全城：灵王气息人尽皆知——S3"缉拿令"全城搜捕的民意基础

**第三季开集（ep49）承接钩**：缉拿令下，全城搜捕——灵婆硬扛官兵，小才带鱼跑路，阿糖断后被抓（03大纲S3第49集）。
