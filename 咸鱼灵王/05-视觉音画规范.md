# 《咸鱼灵王》视觉基调 与 音画一体规范

## 一、视觉基调：港式市井烟火 × 国风水墨灵韵

### 1. 总风格定位

**"旧港片的光，水墨画的灵。"** 市井部分（城寨/灵市）做旧、温暖、拥挤、有生活划痕；灵力部分用2D水墨泼彩+留白，与3D渲染底形成"两层世界"——平凡一层，神性一层。反差本身就是世界观（废的日常 vs 王的真身）。

### 2. 三大色系（全剧锁定，禁止越界）

| 色系 | 色值区间 | 适用 | 情绪 |
|---|---|---|---|
| 城寨暖 | 琥珀黄#E8A33D / 砖红#9E4B2F / 青苔绿#5B7A4A / 暖灰#B8AC9C | 城寨、灵市、日常戏 | 烟火气、安全感 |
| 王者金 | 泼墨金#F2C14E / 留白#FAF6EC / 朱砂点#C03A2B | 觉醒、王威、真身 | 神性+燃 |
| 无相冷 | 青紫#4A4E7C / 机械骨白#D9D4C7 / 纯黑 | 无相阁、夺灵、夜袭 | 压迫、非人 |

季色彩偏移：一季暖 → 二季金黄（食）→ 三季朱红（公堂）→ 四季蓝紫（月）→ 五季金黑对撞。

### 3. 镜头语言（星氏七式）

1. **Punch-zoom**：喜剧急推急拉，一集2~3次，不滥用；
2. **面瘫大特写**：荒诞事件后主角面部定格2秒（笑点靠"没反应"）；
3. **荒诞定格**：动作喜剧 freeze 0.3秒+一帧静音；
4. **慢镜燃点**：爆发必慢镜，配水墨留白（金色泼彩从画面边缘涌入）；
5. **Q版颜艺**：仅限喜剧段，切换时长≤0.5秒，禁止在泪点段使用；
6. **俯拍众生相**：群像名场面统一用垂直俯拍（24集全寨躺平、68集十万人举灯）；
7. **影子叙事**：咸鱼真身一律先用影子/倒影/虚影暗示，正脸留给关键集（17/24/41/48/115集）。

### 4. AI生成一致性规范

- **角色锁**：主角团出三视图+12表情预设+Q版3态，垫图或LoRA锁脸；发型/服装/配饰在档（02档案记忆锚）为硬约束；
- **场景锁**：5大场景库（城寨/灵市/公堂/北境/天梯）各固定3机位光照模板，光线角度写入prompt；
- **Prompt模板**：`[镜头景别/运动] + [主体+动作] + [环境] + [光线色温] + [风格token: ink wash energy effects, HK retro street, cinematic teal-orange grade] + [负词: 现代服饰, 多余手指, 文字乱码]`；
- **帧率与节奏**：打斗24帧手感，喜剧12帧顿挫（秦氏顿帧），觉醒慢镜120帧插帧；
- **分辨率**：制作2160×3840，交付1080×1920，安全区：上1/4留标题钩子、下1/5留台词字幕、左右10%禁关键动作。

## 二、音画一体规范（声音是第二导演）

### 1. 三大声音体系

**BGM三层**：
| 层 | 编制 | 使用 |
|---|---|---|
| 喜剧层 | 唢呐+快板+电鼓点 | 日常、闹剧；节奏与笑点对齐 |
| 燃层 | 民乐齐奏+交响+唢呐主奏 | 觉醒、决战；"唢呐一响，黄金万两" |
| 泪层 | 独奏（二胡/笛/埙）+留白 | 泪点；只允许单乐器，禁止弦乐群煽 |

**音效signature（角色声纹资产，全剧不变）**：
- 咸鱼：翻身"啪叽"+古钟长鸣；说话前有一丝水泡音；
- 灵婆狮吼：玻璃碎+钟磬；
- 小强：复活"嚯——"（同一采样，全剧108次）；
- 王威：万籁俱寂0.5秒→闷雷（"安静"即威胁，声音设计上贯彻"躺平哲学"）；
- 无相阁：所有戏份配逆耳细鸣（4Hz颤），观众说不清但会不适。

**配音腔调（石班瑜式规范）**：
- 小才：尾音上扬"嚯？"，遇险语速快且结巴消失（反差即萌点）；
- 咸鱼：气声慵懒低音，句句不超过十个字，每集≤10句；
- 灵婆：鼻音重、嗓门劈；
- 邪叟：拖长音、气多字少；
- 无相阁主：标准敬语，绝不吼，全程微笑音色——恐怖感来自"太有礼貌"。

### 2. 音画同步铁律

1. **觉醒公式**：所有BGM骤停→心跳三拍（每拍配一个画面细节：眼缝/瞳纹/鱼尾）→唢呐炸。全剧执行同公式，不换——重复本身成为仪式感；
2. **喜剧定格**：freeze≤0.3秒，同期静音1帧，音效落在定格后半拍（延迟出梗）；
3. **末5秒卡点表**：每集强制填写——定格画面/静音时长/悬念音/字幕卡内容，四项齐全才算过；
4. **泪点纪律**：单次音乐硬煽≤8秒，超时改用环境音（风、火、滴水）收尾；
5. **口型**：漫剧允许2D夸张口型（台词重音=口型开合最大帧），喜剧口型超规、严肃口型收敛；
6. **静音即情绪**：每集至少一处1秒以上全静音（信息真空比音墙更抓人）。

### 3. 每集声音预算（90~120秒）

钩子3s（音效主导，无BGM）→ 铺垫30s（BGM喜剧层）→ 冲突40s（层间切换≤2次）→ 爆发/反转25s（燃层或全静音）→ 卡点5s（BGM抽帧+悬念音+黑屏字幕无声）。

## 三、SSS级终审清单（视觉音画维度）

- [ ] 全集色板未越界（三色系+季偏移）；
- [ ] 觉醒公式逐帧一致；
- [ ] signature音效全部命中，无通用音效替代；
- [ ] 每一镜prompt含风格token与负词；
- [ ] 角色脸/服/配饰与档案档一致（脸崩即返工）；
- [ ] 卡点表四项齐全；
- [ ] 泪点无音乐超时煽情；
- [ ] 影子叙事规则未被提前"露真身"。
