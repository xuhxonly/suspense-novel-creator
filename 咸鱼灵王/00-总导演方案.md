# 《咸鱼灵王》总导演方案 · 红果漫剧巅峰热榜冲榜作战书

> 一句话定位：**一条咸鱼灵王的翻身史，一个废柴少年的证明史——做人如果没有梦想，跟咸鱼有什么分别？咸鱼：那你得先问问咸鱼答不答应。**

---

## 一、项目定位（对标红果热榜前十的数据模型）

| 维度 | 设定 |
|---|---|
| 题材 | 无厘头喜剧 × 热血成长 × 东方玄幻灵兽 |
| 体量 | 120集 × 90~150秒，竖屏 9:16，总时长约 4 小时 |
| 结构 | 五季 × 24集，每季完整闭环 + 季终王炸 |
| 情绪配方 | 笑点密度：每集≥3个递进笑点；爽点：每3~5集一次打脸；泪点：每季1次大爆，全程克制 |
| 传播设计 | 每5集埋1个"切片级名场面"（二创素材）；金句前置到每季第1集 |
| 目标曲线 | 第1集完播率>65%（3秒钩子+身份反差）；第3集必须出第一个爽点；第24集出第一波全网切片 |

**爆款内核公式（星爷公式）**：表层爆笑爽文 + 里层小人物尊严。"废"不是笑料，是勋章——全剧每一只废兽都在等一个看见它的人。

## 二、总导演AI指令（可直接投喂任何大模型的总Prompt）

```
【系统指令】你是《咸鱼灵王》总编剧兼总导演。开工前必读三份文件：
01-世界观圣经 / 02-人物档案 / state-项目状态，严禁违背其中任何设定。

铁律一【人设不可破】每个角色的"灵魂场"是绝对律令。情节与灵魂场冲突时，改情节，不改人。
铁律二【每集四件套】①前3秒钩子（动作/反差/悬念开场，禁台词引入）②至少3个递进笑点（动作性笑点优先，rule of three）③1个情绪锚（一个具体的身体细节，非抒情旁白）④末5秒卡点（定格+BGM抽帧+悬念音）。
铁律三【喜剧不解释】笑点靠画面与动作完成，台词单句不超过两行，绝不解释梗。荒诞要一本正经——所有角色对荒诞事件保持严肃反应（正常人锚点原则）。
铁律四【憋-爆发】主角被压到最底才给爆发；每次爆发必须付出可见代价；升级必有成本，无免费午餐。
铁律五【致敬不明说】周星驰经典桥段一律"神似形异"：换皮不换魂，禁止直接搬运台词名，金句须改写成灵兽世界观语汇。
铁律六【状态更新】每写完一集，更新state：伏笔清单（埋设/回收期）、已用梗（同梗30集内禁复用，复用必须变体）、既定事实、角色状态、下一钩子。
铁律七【反AI味】禁用词表：无与伦比/令人叹为观止/深深地/缓缓地/展现出/彰显出/在这个xx的时代。禁三点式总分总议论。禁"仿佛/似乎"堆叠（每段≤1个比喻）。每集必须通过"蒙蔽测试"：遮住角色名，只看台词能认出谁在说话。
铁律八【音画一体】每场戏标注【镜头】【BGM】【音效】三件套；喜剧定格≤0.3秒；觉醒时刻遵循"骤停→3拍心跳→唢呐炸"公式。
输出格式：场次→画面→台词→音画标注。每集成稿后自检00文件的SSS验收十条，不合格重写。
```

## 三、AI生产流水线（五步闭环）

```
① 圣经锁定（本文档全套） → ② 分集剧本批量生成（总指令+03大纲逐集投喂+state回填）
→ ③ 分镜表Prompt化（每集45~60镜：镜号/画面prompt/台词时长/音效） → ④ 图生视频
（角色三视图+12表情包锁脸；单镜5~10s；工具链：Midjourney/即梦出图 → 可灵/Vidu/即梦生成 → 首尾帧控制）
→ ⑤ 音画合成（TTS角色音色锁定 + signature音效库 + BGM分层 + 剪映/PR竖屏包装）
```

**一致性方案**：主角与高频配角先产出角色设定图（三视图/表情12态/Q版3态），用垫图或LoRA锁脸；场景库分5类（猪笼灵寨/灵市/公堂/北境/无相天梯）各定3个固定机位光照模板；全剧色板与风格token统一（见05规范）。

## 四、SSS级验收十条（每集成稿自检）

1. 前3秒有钩子，无台词开场；
2. 末5秒卡点成立（关掉声音仍想点下一集）；
3. 笑点≥3个且递进，无解释性台词；
4. 蒙蔽测试通过（遮名识人）；
5. 每集至少一次信息增量：新信息/新悬念/旧伏笔回收，三者必居其一；
6. 伏笔有回收期，无"天上掉下来的反转"；
7. 爆发有代价，升级有成本；
8. 泪点克制：身体细节承载，禁止音乐硬煽超过8秒；
9. 致敬桥段"神似形异"，无台词照搬；
10. 色板/音效signature/角色音色与本规范一致。
